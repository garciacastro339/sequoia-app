# Sequoia

App de pedidos, agenda y dinero de Sequoia, florería en Ezequiel Montes.

Se publica sola con GitHub Pages en https://garciacastro339.github.io/sequoia-app/ desde la rama `main`.
Los datos viven en la hoja de Google "Sequoia datos"; cada persona entra con su propia cuenta de Google.

- `index.html`, `styles.css`, `app.js`: la app (sin herramientas de compilación).
- `config.js`: ID de la hoja, del calendario y del inicio de sesión de Google (no son secretos).
- `manifest.webmanifest`, `icons/`: para instalarla en la pantalla de inicio del iPhone.
